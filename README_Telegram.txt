МИРЭА Match — авторизация через Telegram

ВАЖНО
- Одного HTML-файла недостаточно для безопасной отправки кодов. В комплекте есть server.js, который обращается к Telegram Bot API.
- Это шаблон: бот и сервер нужно настроить и запустить. Токен бота нельзя помещать в HTML или публиковать.
- Бот не может первым написать человеку: пользователь должен открыть бота по ссылке с сайта и нажать Start.

1. Создай Telegram-бота через @BotFather и скопируй токен.
2. Установи Node.js 18 или новее.
3. Положи МИРЭА_Match_Telegram.html и server.js в одну папку.
4. Задай переменные окружения:
   BOT_TOKEN=токен_от_BotFather
   BOT_USERNAME=имя_бота_без_символа_@
   WEBHOOK_SECRET=длинная_случайная_строка
5. Запусти сервер:
   node server.js
6. Для локальной проверки открой http://localhost:3000 — Telegram webhook из интернета до localhost не достучится.
7. Для реальной работы размести сервер на HTTPS-хостинге, который доступен из интернета, затем установи webhook. Подставь публичный URL сервера и то же значение WEBHOOK_SECRET:
   https://api.telegram.org/botТОКЕН/setWebhook?url=https://ВАШ-ДОМЕН/telegram-webhook&secret_token=ВАШ_WEBHOOK_SECRET

После настройки пользователь нажимает «Получить код в Telegram», открывает бота по ссылке, жмёт Start, получает шестизначный код и вводит его на сайте.

Ограничения демо
- Хранилище пользователей и временных кодов находится в памяти процесса; после перезапуска незавершённые запросы пропадут.
- Данные анкет сайта по-прежнему сохраняются в localStorage браузера.
- Для публичного production-развёртывания добавь HTTPS, ограничение частоты запросов, постоянное хранилище, защиту от перебора кодов и политику конфиденциальности.
