МИРЭА Match — взаимные лайки и Telegram

Изменения:
- «Кто лайкнул» и «Я лайкнул» вынесены в нижнее главное меню.
- При взаимном лайке показывается публичный Telegram username второго пользователя, если он задан.
- Username сохраняется сервером при авторизации и раскрывается только при взаимном лайке.
- Таблица telegram_accounts создаётся автоматически при запуске.

Обновление: замените server.js и МИРЭА_Match_Telegram.html в GitHub. Дождитесь автоматического Deploy на Render. package.json оставьте прежним, если в нём есть pg.


Админка доступна по `/admin`. Для серверной проверки прав администратора задай в Render переменную `ADMIN_TELEGRAM_IDS` со своим числовым Telegram ID (несколько ID через запятую). При деплое `admin.html` должен находиться в той же папке, что и `server.js`.
