# mirea-match

Промокод `CEOPREM` включён по умолчанию и добавляет 7 дней Premium. Дополнительные коды задаются переменной окружения `PREMIUM_PROMO_CODES` в формате `КОД:дни,КОД2:дни`. Каждый код можно применить один раз на аккаунт. Бесплатный доступ: 15 оценок анкет за 5 часов и 3 суперлайка; Premium снимает лимиты, открывает скрытие статуса и дополнительные темы.


## Админка

Рабочий кабинет доступен по адресу `/admin`. Для входа пользователь сначала авторизуется в приложении через Telegram. Затем администратор проверяется на сервере по переменной окружения `ADMIN_TELEGRAM_IDS` — укажи числовой Telegram ID или несколько ID через запятую (без `tg:` и `@`). Например: `123456789,987654321`.

Добавь эту переменную в Environment сервиса Render и перезапусти deploy. Узнать свой ID можно запросом к PostgreSQL: `SELECT account FROM telegram_accounts WHERE username = 'твой_username';` — в переменную нужно перенести только цифры после `tg:`.

Админка показывает общее число аккаунтов и анкет, активность за сутки и неделю, Premium и блокировки. Поиск работает по ID и username. Блокировка бывает на 24 часа, 7 дней, 30 дней или навсегда; причина и действия сохраняются в базе. Активная блокировка проверяется сервером при запросах приложения и при авторизации. В разделе промокодов можно создавать коды с длительностью Premium, датой окончания и лимитом активаций, а также отключать их. `CEOPREM` и коды из `PREMIUM_PROMO_CODES` переносятся в список при запуске базы. В админке также есть рассылка сообщений пользователям через Telegram-бота; она учитывает настройку отключения уведомлений и показывает прогресс отправки. Для рассылки можно выбрать всех пользователей, только аккаунты с активным Premium или без активного Premium. Новые рассылки сохраняют историю и ID отправленных сообщений, чтобы администратор мог попробовать удалить сообщение у получателей или отдельно скрыть запись из истории. Telegram разрешает удалять сообщения бота у получателей только в течение 48 часов; ранее отправленные, ещё не записанные рассылки для такого удаления недоступны.
